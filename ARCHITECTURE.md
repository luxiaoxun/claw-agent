## 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | Vue 3 + Vite + Element Plus + WebSocket |
| 后端 | FastAPI + Python |
| Agent | LangChain (ReAct) |
| LLM | OpenAI API (兼容) |
| 存储 | SQLite + Elasticsearch (可选) |

## 关键单例

| 单例 | 路径 | 职责 |
|------|------|------|
| `agent_manager` | `core/agent/agent_manager.py` | 共享 DeepAgent 实例 |
| `chat_service` | `core/chat/chat_service.py` | HTTP 聊天请求处理 |
| `websocket_service` | `core/websocket/websocket_service.py` | WebSocket 连接管理 |
| `skill_manager` | `core/skill/skill_manager.py` | 技能加载与发现 |
| `database_service` | `service/database_service.py` | 数据库访问 |
